================================================================
                 GIVEAID v2.0 - HƯỚNG DẪN SỬ DỤNG
             ============

Mục đích: Chạy website GiveAID trên máy tính cá nhân để test.

────────────────────────────────────────────────────────────────
  BƯỚC 1 — CÀI ĐẶT MÔI TRƯỜNG (CHỈ LÀM MỘT LẦN)
────────────────────────────────────────────────────────────────

Cần cài 3 thứ trước khi chạy được:

  1) .NET SDK 10
     → Tải: https://dotnet.microsoft.com/download/dotnet/10.0
     → Chọn "SDK 10.0.x → Windows → x64"
     → Mở file .exe vừa tải → nhấn Install → đợi xong → đóng lại

  2) Node.js (phiên bản 18 LTS hoặc 20+)
     → Tải: https://nodejs.org/
     → Nhấn nút "LTS" lớn màu xanh (khoảng 20MB)
     → Mở file .msi vừa tải → Next liên tục → Install → Finish

  3) SQL Server LocalDB ⚠ BẮT BUỘC
     → LocalDB KHÔNG đi kèm .NET SDK. Phải cài riêng.
     → Cách 1 (khuyến nghị): tải SQL Server Express từ
        https://www.microsoft.com/sql-server/sql-server-downloads
        → tick chọn "LocalDB" trong installer.
     → Cách 2: nếu đã có Visual Studio → mở Visual Studio Installer
        → Modify → Individual components → tick "SQL Server Express LocalDB".
     → Kiểm tra sau khi cài: mở cmd mới, gõ
        sqllocaldb versions
       phải ra version SQL Server (vd 17.0.x).

  Sau khi cài xong, MỞ TERMINAL MỚI (Win + R → gõ cmd → Enter)
  rồi gõ:
        dotnet --version
        node --version
        sqllocaldb versions
  Thấy hiện số phiên bản là OK.

────────────────────────────────────────────────────────────────
  BƯỚC 2 — KHỞI ĐỘNG WEBSITE
────────────────────────────────────────────────────────────────

  1) Giải nén thư mục GiveAID-v2.0.zip vào ổ C:\ hoặc Desktop
     (KHÔNG giải nén vào Program Files — sẽ bị lỗi quyền)

  2) Mở thư mục vừa giải nén, TÌM FILE "START.bat"
     → Double-click vào file đó

  3) Lần đầu chạy sẽ hỏi mật khẩu / cảnh báo Windows Defender
     → Chọn "Run anyway" / "Thông tin thêm → Chạy"

  4) Đợi khoảng 20–60 giây (lần đầu tiên lâu hơn vì đang cài đặt)
     → Trình duyệt tự động mở trang http://localhost:3000

  5) Nếu trình duyệt KHÔNG tự mở, mở Chrome/Edge gõ thủ công:
     → http://localhost:3000

────────────────────────────────────────────────────────────────
  BƯỚC 4 — TẮT SERVER
────────────────────────────────────────────────────────────────

  Cách 1 (khuyến nghị): Double-click file "STOP.bat" cùng thư mục.

  Cách 2: Trong cửa sổ cmd đang chạy, nhấn Ctrl + C.

  Cách 3 (khi treo): Mở Task Manager (Ctrl + Shift + Esc) →
    End task các tiến trình tên "dotnet" và "node".

────────────────────────────────────────────────────────────────
  XỬ LÝ LỖI THƯỜNG GẶP
────────────────────────────────────────────────────────────────

  ❌ "Chua cai .NET SDK 10"
     → Quay lại Bước 1, cài .NET SDK 10.

  ❌ "Chua cai Node.js"
     → Quay lại Bước 1, cài Node.js.

  ❌ Cổng 3000 hoặc 5231 bị chiếm
     → Chạy file STOP.bat trước, rồi chạy lại START.bat.

  ❌ npm install lỗi / mạng chậm
     → Mở cmd, gõ:
           cd GiveAID.Client
           npm cache clean --force
           npm install --registry https://registry.npmmirror.com
       (dùng mirror Trung Quốc, nhanh hơn nếu mạng quốc tế chậm)

  ❌ Backend crash với "STATUS_DLL_NOT_FOUND"
     → Đã fix sẵn trong code (dùng managed networking). Nếu vẫn
       lỗi, xóa thư mục GiveAID.Client\node_modules rồi chạy lại.

  ❌ "Database GiveAIDDB not found"
     → Backend sẽ TỰ ĐỘNG tạo database lần đầu. Đợi ~30 giây.

  ❌ Lỗi khác
     → Mở file GiveAID.Client\scripts\backend.log và frontend.log
       để xem chi tiết, rồi gửi cho người giao dự án.
